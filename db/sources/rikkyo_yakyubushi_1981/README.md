# 『立教大学野球部史』の書き起こし

BIG6 Scorebook の試合データは1938年春季からで、それより前の試合はこのサイトにない。その時期の立教の試合を、
次の本から書き起こしたもの。サイトにはまだ取り込んでいない（取り込むかどうか、どう見せるかは未定）。

- 立教大学野球部 編『立教大学野球部史』立教大学野球部（セントポールズ・ベースボール・クラブ）、新座、1981年1月、非売品、546p
- 国立国会図書館デジタルコレクション https://dl.ndl.go.jp/pid/12172714 （DOI 10.11501/12172714）
  - 絶版等で入手困難な資料として、図書館送信・個人向けデジタル化資料送信サービスで閲覧できる（インターネット公開ではない）。
  - そのため、ここに書き起こすのは日付・スコア・成績の数字などの事実だけで、ページの画像や本文の文章は書き写さない。

## ファイル

シーズンごとに `{年}_{spring|autumn}.yml`。

- `source`: 書き起こしたページ（本のページ番号と、国立国会図書館デジタルコレクションのコマの URL）と、書き起こした日。
  その季のページの一部だけを書き起こしたファイルもある（ファイルの冒頭のコメントに範囲を書いている）。
- `games`: 立教の試合（その本に載っているのは立教の試合だけ）。
  - `top` / `bottom` は先攻・後攻（回ごとの得点の上の行が先攻）。回ごとの得点が載っていない試合にはない。
  - `round` は回戦。本に回戦の記載がなく日付の順から推定したものは `round_inferred: true`。
  - `line_score` は回ごとの得点を3回ずつ区切った文字列。`x` は後攻が9回裏を行わなかったこと。
  - `batting` は大学ごとの成績表で、打席の順に `[守備位置, 名前, 打, 安, 三, 四, 失]`。名前・守備位置は印刷の表記のまま（途中出場の選手は「打」「中投」など）。
  - `totals` は成績表の「合計」行。
  - 名前と守備位置だけの成績表は `lineup`（打席の順に `[守備位置, 名前]`）と `lineup_totals`（チームの `[打, 安, 三, 四]`）。
  - `extras` は成績表の下の注記（▽二塁打、▽盗塁、▽犠打 など）。
- `year_batting`: その年のチーム打撃成績と、立教の個人打撃成績。
- `season_batting`: その季のチーム攻撃成績と立教の個人打撃成績。列は `columns` に書く（本によって列が違う）。
  個人の表の列が違うときは `player_columns`、個人の表が一部の選手だけのときは `rikkio_players_partial: true`。
- `batting_leaders`: その季のリーグ全体の個人打撃成績（上位）。
- `standings`: 勝敗表。対戦の欄は印刷のままの文字列（勝った試合数。引分を △ で示す本もある）。
  対戦の欄のあとの列（勝・分・勝点・率）は `columns` に、率が勝数÷試合数か勝数÷（勝数＋敗数）かは `average` に書く。
- `team_fielding`: チーム守備成績。
- `other_games`: その他の戦績（リーグ戦以外の試合）。年がわからないものは `month_day` だけを書く。
- `tour`: 遠征の戦績と一行。日付や球場がない試合もある。
- `rikkio_roster`: その年の部員。
- `discrepancies`: 本の中で食い違うところ（合計が合わない、名簿にない名前など）。値は印刷のまま書き起こし、
  どちらが正しいかを決めずにここに残す。

大学はこのサイトの slug（`waseda keio meiji hosei tokyo rikkio`。帝大は `tokyo`）。

`test/models/source_transcriptions_test.rb` が、回ごとの得点の合計とスコア、成績表の各列の合計と「合計」行、
チーム打撃成績の塁打数と打率、立教の個人打撃成績の各列の合計とチームの行、個人打撃成績の打率、
勝敗表の勝数・引分・敗数・勝点・率、チーム守備成績の比率（四捨五入か切り捨て）を照らし合わせる。`discrepancies` に挙げたところは除く。
