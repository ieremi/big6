# 開発者向けの解説

このアプリ（東京六大学野球の記録サイト Big6）を開発する人向けの解説です。コードの全体像は、リポジトリ直下の [CLAUDE.md](../CLAUDE.md) にまとめてあります。ここでは、外部サイトの仕様のように、コードを読んでもわからないことを書きます。

## 外部サイト

- [連盟公式サイト（big6.gr.jp）の試合ページのURL](league-site-game-page.md)
  - 試合中の暫定スコアや先発メンバーの取り込みに使っているページです。URLのパラメータと、回戦番号の付け方が Scorebook と違う点をまとめています。

## 書き方

- 外部サイトの仕様は、公開されている説明がなく、実際に試して調べたものです。**いつ確かめたか**を書いておいてください。サイトが変わったときに、どこまで信用してよいかの目安になります。
- 対応するコードのクラス名を書いておくと、あとで追いやすくなります。
