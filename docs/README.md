# 東京六大学野球のデータを扱う開発者向けの解説

東京六大学野球のデータを扱うソフトウェアを作る人向けに、データの入手先の仕様と注意点をまとめています。記録サイト、分析ツール、アプリなどを想定しています。

どの入手先も、公式の仕様書を公開していません。ここに書いてあるのは、実際に試して調べた内容です。各ページに**確認した日付**を書いてあります。相手のサイトが変われば、仕様も変わりえます。

## データの入手先

| 入手先 | わかること | 解説 |
|---|---|---|
| 東京六大学野球連盟 公式サイト（big6.gr.jp） | 日程、試合中のスコア、先発メンバー、ボックススコア（2005年以降） | [試合ページのURL](league-site-game-page.md) |
| BIG6 Scorebook（big6scorebook.jp） | 1925年以降の試合結果、選手名鑑、試合ごとの成績（一部のシーズンのみ） | 準備中 |
| このサイト（Big6）の Web API | 上の2つを整理したデータ（試合、シーズン、選手、ランキング）を JSON で | [Web API の説明](https://big6.onrender.com/api/docs) |

## 使うときのお願い

- **アクセスは間隔をあけて**：どのサイトにも、利用のための API キーや利用規約上の案内はありません。まとめて取得するときは、1秒に1回程度に抑えるなど、相手のサーバーに負担をかけないようにしてください。
- **公式の記録と照らし合わせる**：試合ごとのデータには抜けや誤りがあります（各ページの「注意すること」を参照）。通算記録などは、公式の記録と差が出ることがあります。

## このサイトについて

これらの解説は、東京六大学野球の記録サイト [Big6](https://big6.onrender.com/) を作るなかで調べたものです。このサイトのソースコードは [GitHub](https://github.com/ieremi/big6) で公開しているので、実装例として参考にしてください。
