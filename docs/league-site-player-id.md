# 連盟公式サイト（big6.gr.jp）の選手ID

連盟公式サイトの[試合ページ](league-site-game-page.md)のボックススコアでは、選手名が選手ごとのページへのリンクになっています。リンク先のURLに、連盟のサイトでの選手IDが入っています。

```
https://big6.gr.jp/system/prog/kojinseiseki_career_individual.php?m=pc&p=AK23UT0
```

ボックススコアの選手名は「上田」「林純」のような短い形なので、名前だけでは選手名鑑の選手と確実には結びつきません。IDを使うと、入学年と大学がわかり、在学中の選手ならフルネームと出身校もわかります。

（2026年9月30日に確認）

## IDの形

2009年以降の試合ページのIDは、次の形です。

| 部分 | 例（`AK23UT0`） | 意味 |
|---|---|---|
| 1文字目 | `A` | 確かめた範囲では、いつも `A` |
| 2文字目 | `K` | 大学の頭文字（`W` 早大、`K` 慶大、`M` 明大、`H` 法大、`T` 東大、`R` 立大）。試合ページのスコアボードの頭文字と同じ |
| 3〜4文字目 | `23` | 入学年の下2桁 |
| 5〜6文字目 | `UT` | 姓と名の読みのローマ字の頭文字（上田 太陽 ＝ **U**eda **T**aiyou） |
| 7文字目 | `0` | 通し番号。大学・入学年・頭文字が同じ選手を区別する |

通し番号の例として、慶大の2023年入学の吉開 鉄朗は `AK23YT0`、吉野 太陽は `AK23YT1` です。どちらが `0` になるかの決まりはわかっていません。そのため、IDを名鑑の情報から組み立てることはできません。ボックススコアのリンクから読み取る必要があります。

試合の年によって、IDの形がちがいます。

| 試合の年 | IDの例 |
|---|---|
| 2005年 | どのリンクも `p=ID` という文字そのもので、IDがない |
| 2006〜2008年 | `T2003MORIYAMAS`（大学の頭文字＋入学年4桁＋姓のローマ字＋名の頭文字） |
| 2009年〜 | `AW07MH0`（上の表の形） |

## 選手のページ

IDのページには、見出しと、シーズンごとのリーグ戦と新人戦の成績があります。見出しに出る内容は、選手によってちがいます。

- **在学中の選手**：「上田 太陽 （2023年入学・國學院久我山）」のように、フルネームと、略していない出身校が出ます。ボックススコアでは略されていた出身校（「國學院久我」）も、ここでは全部出ます。
- **卒業した選手**：「（2018年入学・）」のように入学年だけで、名前と出身校は出ません。2018〜2022年入学の選手で確かめたところ、どれも名前がありませんでした。成績の表は残っています。

存在しないIDでもエラーにはならず、「（2023年入学・）」のような見出しだけのページが返ります。成績の行がないことで見分けられます。

## 使いみち

- **試合中のボックススコアの選手を名鑑と結びつける**：試合に出るのは在学中の選手なので、IDのページでフルネーム・入学年・出身校がわかります。短い名前と略された出身校から推測するより確実です。1人につき1回ページを読めば、その後はIDだけで結びつけられます。
- **成績の照合**：選手ごとのシーズン成績があるので、ほかの入手先（BIG6 Scorebook など）の成績と比べる材料になります。卒業した選手のページにも成績は残っています。
