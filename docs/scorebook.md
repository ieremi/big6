# BIG6 Scorebook（big6scorebook.jp）

BIG6 Scorebook（東京六大学野球 公式記録室）は、1925年以降のリーグ戦の試合結果、選手名鑑、試合ごとの成績を載せているサイトです。

公開された仕様はありません。以下は、実際に試して確かめた内容です。確認した日付は項目ごとに書いてあります。

## 取得できるもの

| 内容 | 取得先 | 形式 |
|---|---|---|
| シーズンの全試合（スコア、観衆、試合時間、ベンチ入りメンバーなど） | 試合検索 API | JSON |
| 選手名鑑（入学年ごと） | 選手検索 API | JSON |
| 1試合の打撃・投手成績（ボックススコア） | 試合ページ | HTML に埋め込まれた JSON |
| 1人の選手の、試合ごと・シーズンごとの成績 | 選手ページ | HTML に埋め込まれた JSON |
| 歴代記録（通算本塁打など） | 記録ページ | HTML の表 |

## 試合検索 API（2026-09-27 確認）

```
https://big6scorebook.jp/api/game/search?league=リーグ戦&season=2026秋
```

- `season` は西暦＋「春」または「秋」です（URLエンコードが必要）。
- 返り値は `{"data": [...]}` で、そのシーズンの全試合が入っています。中止の試合や、まだ行っていない試合も含まれます。

1試合の主な項目：

| 項目 | 例 | 内容 |
|---|---|---|
| `id` | `2026091201` | 試合ID（下の「ID の形」を参照） |
| `gameDay` | `"2026-09-12T00:00:00.000Z"` | 試合の日付。時刻の部分は常に 0 時（UTC）で、日付の部分が日本の日付 |
| `round` | `"1回戦"` | 回戦。**中止のあとも、最初の日程の番号のまま**のことがある（下の注意点を参照） |
| `gameOrder` | `1` | その日の第何試合か |
| `topTeamId` / `bottomTeamId` | `2` / `5` | 先攻・後攻の大学（下の大学ID） |
| `gameStatus` | `"試合終了"` | `試合前`・`試合中`・`試合終了`・`中止`・`ノーゲーム` |
| `runs1Top` … `runs18Bottom` | `"0"` | イニングごとの得点（**文字列**）。行っていないイニングは `null` |
| `runsTotalTop` / `hitsTotalTop` / `errorsTotalTop` | `"6"` | 得点・安打・失策の合計（文字列） |
| `attendance` | `"7,000 "` | 観衆。**カンマと末尾の空白が入った文字列** |
| `gameTimeNet` | `"2時間25分"` | 試合時間 |
| `isCounted` | `true` | `false` は優勝決定戦。シーズン成績や通算には数えない試合 |
| `GameMember` | `[...]` | ベンチ入りメンバー（背番号、学年、先発の打順・守備など）。**2021年以降の試合だけ** |

大学ID：

| 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|
| 早大 | 慶大 | 明大 | 法大 | 東大 | 立大 |

## 選手検索 API（2026-09-27 確認）

```
https://big6scorebook.jp/api/member/search?page=1&enter_year_west=2023
```

- 返り値は `{"success": true, "members": [...], "hasNextPage": true}` です。1ページに20人ずつ入っています。
- `enter_year_west`（入学年）で絞り込めます。付けないと全員で、およそ670ページありました。
- 部長・監督などのスタッフには、入学年がない人がいます。入学年で絞り込むと、この人たちは出てきません。
- 主な項目：
  - `id`（選手ID）、`nameFull`、`nameFamilyKana` / `nameFirstKana`、`teamId`、`enterYearWest`、`playerPosition`、`pitchingHand` / `battingHand`、`highSchool`
  - `teamPositon`（役割。**綴りは API のまま** `Positon`）
  - `enrollmentActive`（`1` 在籍中、`2` 卒業、`3` 退部など）

## 試合ページ（2026-09-25 確認）

```
https://big6scorebook.jp/game/2025100502
```

HTML の `<script id="__NEXT_DATA__">` に JSON が埋め込まれています。`props.pageProps.gameStats` の中身は次のとおりです。

- `batterTop` / `batterBottom`：先攻・後攻の打者ごとの成績
- `pitcherTop` / `pitcherBottom`：投手ごとの成績
- `catcherTop` / `catcherBottom`：捕手ごとの成績
- `seasonStats`

打者1人の項目は `memberId`（選手ID）、`teamId`、`position`、`pa`（打席）、`ab`（打数）、`hb`（安打）、`twob`（二塁打）、`threeb`（三塁打）、`hrb`（本塁打）、`rbi`（打点）、`rb`（得点）、`sob`（三振）、`bbTotal`（四死球）、`sac`（犠打・犠飛）、`sb`（盗塁）、`cs`（盗塁死）、`gidp`（併殺打）、`error`（失策）などです。

- `position` は、古い試合では漢字（`"[三]"`、`"打一"`）、新しい試合では番号（`"[4]"`、`"H"`）です。
  - 番号の対応：1 投、2 捕、3 一、4 二、5 三、6 遊、7 左、8 中、9 右、D 指名打者、H 代打
  - `[ ]` は先発を表します。
- ページの見た目には先発メンバーの表があります。ただしこれは打順と名前の表で、**打撃成績の表ではありません**。打撃成績は埋め込まれた JSON にだけあります。

## 選手ページ（2026-09-25 確認）

```
https://big6scorebook.jp/member/20234025
```

`props.pageProps.gameStatsBatterData` に、その選手の打撃成績が入っています。

- `subTotals`：シーズンごと
- `total`：通算
- `leagues`：リーグ戦の試合ごと
- `others`：優勝決定戦など

`leagues` の1行には、試合検索 API と同じ試合ID（`gameId`）と、その試合の情報（`gameInfo`：日付、回戦、`topTeam`・`bottomTeam`）が付いています。投手成績は `gameStatsPitcherData` で、形は同じです。

## ID の形（2026-09-27 確認）

- **試合ID**：`YYYYMMDD` ＋ その日の第何試合か（2桁）。例：`2025100502` は2025年10月5日の第2試合。
- **選手ID**：入学年（4桁）＋ 大学ID（1桁）＋ 連番（3桁）。例：`20231007` は2023年入学・早大の7番目。

ただし、どちらもそう見えるというだけで、公式に決まった規則かどうかはわかりません。

## 注意点

### 試合ごとの打撃成績がないシーズンが多い（2026-09-23 確認）

1925年以降の全204シーズンのうち101シーズンで、試合ページにも選手ページにも、試合ごとの打撃成績が見つかりませんでした。

| 期間 |
|---|
| 1925年春季〜1945年秋季 |
| 1947年春季〜1960年秋季 |
| 1961年秋季、1962年春季〜1966年秋季 |
| 1968年春季〜1969年秋季、1970年秋季、1971年春季・秋季 |
| 1975年秋季、1976年春季・秋季 |
| 2010年春季〜2011年秋季 |
| 2014年春季〜2016年秋季 |

- 選手ページのシーズン成績（`subTotals`）も、試合ごとの成績を足したものなので、同じシーズンが欠けています。
- 一方、記録ページ（`/stats/record/personal/batting`）の歴代記録には、これらのシーズンの記録も含まれています（例：1965〜68年の田淵 幸一の通算本塁打22本）。
- そのため、試合ごとの成績を足し上げた通算記録は、歴代記録より少なくなります。例：岩見 雅紀の通算本塁打は、試合ごとの成績では12本（27試合分）、歴代記録では21本。

### 記録していない値は `null`（2026-09-23 確認）

得点・併殺打・盗塁・犠打・三塁打・失策・二塁打などは、古い試合を中心に `null` のことがあります。サイト上では「-」と表示されます。`0` とは意味が違います。

また、試合ページの塁打（`tb`）は、打者の行のおよそ3分の1で `0` でした（2026-09-20 確認）。値が入っている行では、安打＋二塁打＋2×三塁打＋3×本塁打と一致します。

### 回戦番号が中止のあとも変わらないことがある（2026-09-27 確認）

中止があったとき、試合検索 API の `round` は最初の日程の番号のままのことがあります。例：2026年秋季の早大 vs 明大は、9/26 の1回戦が中止になりました。

- 翌日の試合：`round` は「2回戦」、連盟公式サイトでは1回戦
- 9/28 の振り替え：`round` は「1回戦」、連盟公式サイトでは2回戦

試合検索 API（`https://big6scorebook.jp/api/game/search?league=リーグ戦&season=2026秋`）の、この3試合の行です（主な項目だけ）。

```json
{"id": 2026092602, "gameDay": "2026-09-26T00:00:00.000Z", "round": "1回戦", "gameOrder": 2, "topTeamId": 1, "bottomTeamId": 3, "gameStatus": "中止"}
{"id": 2026092701, "gameDay": "2026-09-27T00:00:00.000Z", "round": "2回戦", "gameOrder": 1, "topTeamId": 3, "bottomTeamId": 1, "gameStatus": "試合前"}
{"id": 2026092802, "gameDay": "2026-09-28T00:00:00.000Z", "round": "1回戦", "gameOrder": 2, "topTeamId": 1, "bottomTeamId": 3, "gameStatus": "試合前"}
```

9/27 の試合の、連盟公式サイトのページです。

- `https://big6.gr.jp/system/prog/game.php?m=pc&e=league&s=2026a&gd=2026-09-27&gnd=1&vs=MW1`：データがあるページ（およそ 62KB）
- `https://big6.gr.jp/system/prog/game.php?m=pc&e=league&s=2026a&gd=2026-09-27&gnd=1&vs=MW2`：`round` のとおり2回戦にすると、空のページ（およそ 50KB）

連盟公式サイトは、実際に行った順に番号を付けています（[連盟公式サイトの試合ページのURL](league-site-game-page.md)を参照）。

### 試合ページに打撃成績がない試合がある（2026-09-25 確認）

試合ページの投手・捕手の成績はあるのに、`batterTop` / `batterBottom` が空の試合があります。その試合の打撃成績は、選手ページにだけあり、しかも**同じ日の別の試合の試合ID**で登録されています。

- 2025年10月5日 早大 vs 法大 2回戦（`2025100502`）：法大の選手の行が `2025100501`（東大 vs 慶大）で登録されている
- 2019年4月28日 慶大 vs 法大 2回戦（`2019042802`）：同様に `2019042801`（明大 vs 早大）で登録されている

選手ページの行の `teamId` が、`gameInfo` の `topTeam`・`bottomTeam` のどちらでもないことで見分けられます。

### 別の試合の成績表が紛れ込んでいることがある（2026-09-25 確認）

1967年5月3日の法大の選手には、選手ページに同じ日の行が2つずつあります。

- 1つは正しい試合（早大 vs 法大 4回戦）の行で、試合ページと一致します。
- もう1つは立大 vs 慶大 4回戦の試合IDで登録されています。打順と守備は同じ9人ですが、成績がまったく違います。

どの試合の成績なのかはわかっていません。

### 同じ試合が2行ある（2026-09-23 確認）

選手ページや試合ページで、同じ選手・同じ試合の行が2つあることがあります。例：岡田 彰布 1978年5月29日、安本 竜二 2019年4月13日。調べた79人のうち20件ありました。選手ページのシーズン成績は、2行とも足しています。

### 両チームが同じ大学の試合がある（2026-09-25 確認）

選手ページの `gameInfo` で、`topTeam` と `bottomTeam` が同じ大学になっている試合があります。例：1981年5月30日「早大 vs 早大」、1997年5月18日「法大 vs 法大」。試合検索 API でも、2005年より前の試合に、同じような試合が6試合ありました。

### 記録ページの表記の揺れ（2026-09-23 確認）

歴代記録のページで、同じ選手の名前が表によって違うことがあります（「堀場 秀孝」と「堀場 英孝」）。

## アクセスの頻度

API キーや、データの利用についての案内はありません。Big6 では、1秒に1回程度の間隔で取得しています。選手ページで全選手を確かめる処理は、夜間に少しずつ行っています。
